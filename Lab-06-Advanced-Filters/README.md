## 📖 Overview
This repository contains the first part of my SQL filtering implementations. The script establishes an HR database and utilizes fundamental comparison and logical operators to extract specific data subsets based on strict business rules[cite: 11].

## 🧠 Concepts Applied
* **Comparison Operators:** Used `>`, `<=`, `=`, and `!=` to evaluate numeric thresholds and exact text matches.
* **Logical Operators:** Applied `AND` to enforce multiple overlapping conditions, and `OR` to broaden search parameters across different columns.
